# Acme Beauty Salon

Production website for [Acme Beauty Salon](https://acmebeautysalon.vercel.app), 
a women's beauty salon based in Nagda, Madhya Pradesh.

## Features
- Responsive multi-page website
- GSAP scroll-triggered animations
- Custom cursor
- WhatsApp booking integration
- Full gallery with category filters
- Owner dashboard (in development)

## Tech Stack
HTML · CSS · JavaScript · GSAP · Vercel
